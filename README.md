# שם קוד (Codenames בעברית)

משחק קבוצתי למובייל שרץ כולו בדפדפן, בלי שרת משלו. מתאים ל-GitHub Pages.

- **המארח** (טלפון אחד) מחזיק את מצב המשחק ב-`localStorage` ומשמש כ"שרת".
- **שאר השחקנים** מצטרפים עם קוד בן 4 תווים (או קישור) וחיבור ישיר WebRTC דרך [PeerJS](https://peerjs.com).
- מפתח הקלפים נשלח רק לראשי המרגלים, כך שסוכנים לא יכולים לרמות דרך כלי המפתחים.
- אם המארח מרענן או סוגר את הדף, המשחק משוחזר והשחקנים מתחברים מחדש אוטומטית.

## קבצים
- `game.js` – מנוע המשחק (לוגיקה טהורה) · `words.js` – רשימת מילים
- `app.js` – ממשק ורשת · `style.css` · `index.html` · `vendor/peerjs.min.js`

## בדיקות
```
node test/game.test.js          # מנוע המשחק
node test/e2e.js [URL]          # 4 שחקנים בדפדפן אמיתי (playwright-core + Chrome)
```

## הגבלות
- המארח צריך להשאיר את הדף פתוח (המסך דלוק). ב-iOS דף ברקע נעצר.
- ללא שרת TURN: ברשתות סלולריות מסוימות (CGNAT סימטרי) החיבור עלול להיכשל. אפשר להוסיף שרת TURN במערך `ICE` ב-`app.js`.
- ברוקר האיתות הוא הענן הציבורי של PeerJS (משמש רק להתחברות הראשונית, לא לנתוני המשחק).
